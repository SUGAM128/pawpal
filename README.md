## 🛠️ Project Setup Instructions

Follow the steps below to run this project on your local machine using XAMPP.

---

### ✅ Requirements

- [XAMPP](https://www.apachefriends.org/index.html) installed on your system

---

### 📦 Installation Steps

1. **Install XAMPP**  
   Download and install XAMPP from the official website.

2. **Start Apache and MySQL**  
   Open the **XAMPP Control Panel** and start the following services:
   - ✅ Apache
   - ✅ MySQL

3. **Place Project in `htdocs`**  
  C:\xampp\htdocs\

markdown
Copy
Edit

4. **Import the Database**  
- Open your browser and go to:  
  ```
  http://localhost/phpmyadmin/
  ```
- Click on **Import** from the top menu.
- Choose the file named `petmarket.sql` from the project folder.
- Click **Go** to import the database.

5. **Run the Project**  
Open your browser and go to:
http://localhost/furreverfriends/
